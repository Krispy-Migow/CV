# CV

Proyecto de computer vision.

## Estructura

- `data/raw` – datos originales (no versionados)
- `data/processed` – datos procesados (no versionados)
- `notebooks` – exploración y experimentos
- `src` – código fuente
- `models` – pesos de modelos (no versionados)
- `configs` – archivos de configuración
- `outputs` – resultados generados (no versionados)
- `tests` – pruebas
- `docs` – documentación
